# Development decision log

Each workstream owns one log file in this directory. Entries record significant decisions, alternatives, evidence, deviations, and unresolved issues. Cross-cutting integration and final status decisions have dedicated logs.

| Workstream | Log |

| Integrated runtime verification | [`integration-runtime.md`](integration-runtime.md) |
| Final operations/status documentation | [`documentation.md`](documentation.md) |
| Infrastructure and operations | [`infrastructure.md`](infrastructure.md) |
| Backend foundation | [`backend.md`](backend.md) |
| Backend HTTP API | [`backend-http.md`](backend-http.md) |
| Background jobs and delivery | [`background.md`](background.md) |
| Recurrence | [`recurrence.md`](recurrence.md) |
| Frontend foundation | [`frontend.md`](frontend.md) |
| Frontend features | [`frontend-features.md`](frontend-features.md) |
| Frontend calendar/recurrence | [`frontend-calendar.md`](frontend-calendar.md) |
| Contract hardening | [`contract-hardening.md`](contract-hardening.md) |

The index lists logs present on this branch only. Evidence from an active worktree is not final until its log and changes are reviewed and merged.
